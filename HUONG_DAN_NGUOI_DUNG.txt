HƯỚNG DẪN CHO NGƯỜI KHÔNG BIẾT CODE
===================================

CÀI MỘT LẦN (Windows):
  1. Cài Python 3.10 hoặc 3.11 từ https://www.python.org/downloads/
     -> Khi cài, TÍCH vào ô "Add python.exe to PATH".
  2. Giải nén thư mục này ra chỗ nào cũng được (đừng chạy trực tiếp trong file zip).
  3. Bấm đúp vào  CHAY_WINDOWS.bat
     Lần đầu nó tự cài thư viện (vài phút, cần mạng). Từ lần sau mở lên ngay.

DÙNG:
  1. Bấm "Chọn file..." -> chọn video.
  2. (Tuỳ chọn) đổi vùng phụ đề / loại chữ Hán.
  3. Bấm BẮT ĐẦU. Chờ chạy xong.
  4. Bấm "Mở thư mục kết quả" -> lấy file .srtpx (cạnh video).
  5. Mở vài ảnh trong thư mục "debug": khung ĐỎ phải bao đúng chữ phụ đề.
     Mặc định quét toàn bộ khung hình. Muốn nhanh hơn thì đổi "Vùng có phụ đề" thành
     "Dải dưới 25%" rồi chạy lại.

MẸO:
  - Video dài: giảm "số khung hình/giây" xuống 10 cho nhanh.
  - Chạy thử bằng video ngắn 1 phút trước.

CÁCH NHANH NHẤT (Windows):
  Bấm đúp  Cai_Dat_Mot_Phat.bat  -> tự cài Python (nếu thiếu), thư viện, và tạo
  shortcut "Boc Hardsub" ngoài Desktop. Các lần sau chỉ cần bấm shortcut đó.

DAY CODE LEN GIT (cho nguoi phat trien):
  Bam dup Day_Len_Git.bat -> tu cai Git/GitHub CLI neu thieu, tu tao repo
  "hardsub-extract-tool" (rieng tu) tren GitHub, tu commit va push.
  Lan dau se mo trinh duyet de dang nhap GitHub 1 lan. Lan sau bam la xong.
  Muon dung repo co san: dan link vao dong $RemoteUrl trong ci\day_len_git.ps1.

CHAY TREN MAY AO CUA GITHUB (GitHub Actions):
  CACH TU DONG: day video vao thu muc input/ cua repo (Add file -> Upload files,
  hoac git push). GitHub tu chay, boc xong luu file .srtpx vao thu muc output/
  (cung ten video) va dong thoi co o muc Artifacts cua lan chay. Video nao da co
  ket qua trong output/ thi khong boc lai.
  CACH TAY: tab Actions -> "Boc hardsub" -> Run workflow, dan drive_link / video_url.
